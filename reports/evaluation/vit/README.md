# ViT Evaluation Outputs

Place generated figures, tables, and animations for ViT runs here.

Recommended structure:

- `reports/evaluation/vit/<run_id>/`
  - `loss_curves.png`
  - `metrics_table.csv` or `metrics_table.md`
  - `pred_vs_gt.png`
  - `residual_maps.png`
  - `attention_spatial.png`
  - `attention_temporal.png`
  - `forecast_animation.gif`
